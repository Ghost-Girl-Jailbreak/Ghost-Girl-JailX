# Troubleshooting

### "No applicable update data was found"
- USB must be **FAT32** with an **MBR** partition table.
- File must be at the **root** of the USB.
- Folder must be named exactly `PS3/UPDATE/`.

### Console freezes during install
- Do **not** power off. Wait 5 minutes.
- If stuck, hard reboot and retry with a different USB drive.

### Jailbreak menu not appearing
- Re-run the installer.
- Confirm your firmware matches the supported range.

### Still stuck?
Open an [Issue](../../issues) with your PS3 model and firmware.
